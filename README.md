# Portfolio

A recruiter-focused portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000/en](http://localhost:3000/en).

## Content and design

- English site content: `content/en/`
- Design tokens and global styles: `app/globals.css`
- Locale route: `app/[locale]/`
